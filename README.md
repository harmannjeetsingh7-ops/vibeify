# Vibeify

Vibeify is a music discovery and playlist management website created using Next.js, React and TypeScript for COMP2112.

## Features

- Add, edit and delete favourite songs.
- Discover Punjabi music using the iTunes Search API.
- Explore music based on different moods.
- Personalized welcome message.
- Shared navigation and responsive design.

## Technologies Used

- Next.js and React
- TypeScript
- CSS and Tailwind CSS
- React Hook Form
- Props, useState, useEffect and useContext
- Fetch API

## Getting Started
npm install
npm run dev
Open http://localhost:3000 in your browser.
